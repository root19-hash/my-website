\##Usage

3 Realistic User Tasks

1. Finding Printing Service Information:
   The user can:
   • View available printing/photocopying services
   • See paper sizes or printing types
   • Read instructions for using the service
   • Find relevant information before going to the library
   Example:
   "I want to know what printing services the library provides."

2. Submit a print request:
   The user can fill out a print request form, such as:
   • Name
   • Student/Staff ID
   • Email
   • Document name
   • Number of copies
   • Print type
   • Paper size
   • Additional instructions
   Then they can click Submit.
   This is especially useful because my assignment requires at least one substantial form with labels, suitable input types, and HTML validation.

3. Find contact and service information:
   The user can:
   • Find the library's location
   • View opening hours
   • Find phone/email/contact details
   • Get directions or other relevant information
   Example:
   "I need to know where the printing service is and when it's open."
