# Project Name: Matheson Library Printing Services

## 1. Theme

I chose to create a website for the library's printing services.
The website is called **Matheson Library Printing Services**.

## 2. Target Audience

The main users of this website are:

- Students
- Staff
- Members of the public

## Features

- **Semantic HTML5:** All five pages use proper HTML5 structural elements for clear organisation and accessibility.
- **Global Navigation:** A consistent navigation bar is included across all pages for easy browsing.
- **Contact & Booking Form:** Includes labelled fields, suitable input types, and HTML5 validation.
- **Structured Content:** Uses headings, paragraphs, lists, tables, and figures with captions.
- **Multimedia:** Includes embedded video and Google Maps for improved user engagement.
- **Accessibility:** Uses descriptive image `alt` text, meaningful links, metadata, and logical headings.
- **CSS Styling:** Uses an external stylesheet for consistent layout, typography, spacing, and readability.

## Usage

### Realistic User Tasks

#### 1. Finding Printing Service Information

Users can:

- View available printing and photocopying services
- See available paper sizes and printing types
- Read instructions for using the printing service
- Find relevant information before visiting the library

**Example user task:**

> "I want to know what printing services the library provides."

#### 2. Submit a Print Request

Users can complete a print request form containing information such as:

- Name
- Student/Staff ID
- Email
- Document name
- Number of copies
- Print type
- Paper size
- Additional instructions

This feature is especially useful because the assignment requires at least one substantial form with labels, suitable input types, and HTML5 validation.

#### 3. Find Contact and Service Information

Users can:

- Find the library's location
- View opening hours
- Find phone, email, and other contact details
- Get directions and other relevant information

**Example user task:**

> "I need to know where the printing service is and when it is open."
